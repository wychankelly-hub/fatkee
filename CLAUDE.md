# Project: 發記冰室數據大危機 (HKDSE SQL revision game)

Read `SPEC.md` fully before writing any code. It is the source of truth.

- Game content lives in `content/*.py`; run `python3 build.py` to validate and regenerate `levels.json`. Never edit `levels.json` by hand.
- The JS answer checker must match `preprocess()`, the custom functions, `LINT` and the comparison logic in `build.py`.
- Main device is iPhone Safari. Students type only English/digits/symbols; all UI text is Traditional Chinese (書面語). No drag-and-drop.
